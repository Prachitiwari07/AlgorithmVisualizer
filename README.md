# Algorithm Visualizer

An interactive web-based learning tool that helps students understand sorting algorithms through visual animations.

## Features

- Visualize six sorting algorithms:
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Quick Sort
  - Counting Sort
- Generate a random array.
- Adjust array size and animation speed.
- Start, pause, and reset the visualization.
- Track comparisons and swaps.
- View algorithm time and space complexity.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Select a sorting algorithm and start the visualization.
